# NES Smart Files v0.2 – تحديث أولي للاختبار

## التغييرات المنفذة

- واجهة مستقلة للفهرسة تبين مرحلة اكتشاف الملفات والإجمالي بعد الاكتشاف، وعدد المكتملة والبانتظار والفاشلة.
- إحصاء ملفات PDF والصور والفيديو والصوت والمستندات وExcel والعروض والأرشيفات والأكواد والملفات النصية.
- فهرسة على مرحلتين: اكتشاف سريع وبالتجميع عبر SQLite UPSERT ثم استخراج محتوى الملفات الجديدة/المتغيرة فحسب.
- عدم فك ترميز الوسائط أثناء المسح السريع. هذه الملفات تُفهرَس بياناتها الوصفية فقط في هذه النسخة.
- ترقية قاعدة البيانات v1 إلى v2 بدون حذف الملفات أو المقاطع والمحادثات.
- إدارة نماذج GGUF في شاشة مستقلة: تنزيل نموذجين معروفين ببصمات SHA256، استيراد GGUF أو ZIP أو مجلد، عرض المسار، حجم الملف وترويسة GGUF، وحالة النموذج والفشل.
- يمكن اختيار Qwen3-0.6B Q4_0 (نصّي) بديلًا عند إخفاق Qwen3.5-0.8B؛ لا ضمان للتحميل قبل اختبار هاتف فعلي.
- إصلاح إعادة المحاولة بعد Error من واجهة llama.cpp عبر cleanUp() قبل loadModel().
- إرجاء تنظيف محرك llama عند إعادة إنشاء MainActivity في العملية نفسها لتجنب تعطيل singleton بعد destroy().
- تضمين إمكانية توقيع APK بمفتاح ثابت خاص بالمطور، باستخدام GitHub Actions Secrets؛ لا تحفظ مفاتيح التوقيع بالمستودع العام.

## الحالة التنفيذية

هذه ملفات مصدر للتجربة. لم يجر تجميعها أو تثبيتها على هاتف داخل بيئة إنشاء الحزمة. ستتم مراجعة أخطاء Kotlin وGradle من GitHub Actions عند رفع التحديث.

**غير متوفر بعد:** البحث الدلالي الفعلي، OCR للصور، التفريغ الصوتي، فهم المشاهد، إدارة الملفات نقل/نسخ/حذف. لا تعرض الشاشة ادعاء وجود فهم مرئي/صوتي.

## تحذير تحديث V0.1

توقيع Debug من GitHub Actions كان مؤقتًا غالبًا، فلا يتطابق مع مفتاح الإصدار المستقر الجديد. Android يرفض التحديث فوق التطبيق القديم بمفتاح مختلف حتى لو بقي `applicationId = ye.nes.smartfiles` وزاد `versionCode`. لا تحذف القديم قبل نسخ قاعدة بياناته وملفات النماذج والمحادثات. يمكن محاولة نسخ التطبيق Debug عبر ADB Wireless Debugging + `run-as` قبل إزالته، ثم استعادته بعد تثبيت النسخة الموقّعة بنفس المعرّف. أدوات النسخ موجودة في `scripts/nes-backup-existing.sh` و`nes-restore-data.sh`. يجب اختبار توفر `run-as` أولًا.

من النسخة v0.2 فما بعد، عند استخدام نفس keystore المستقر ورفع versionCode، يمكن تثبيت APK كتحديث عادي.
