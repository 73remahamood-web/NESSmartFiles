- [ ] إعادة الفهرسة: المحتوى غير المتغير لا يعاد استخراجه.
- [ ] ملف حُذف: لا يدعي التطبيق الحذف من نتائج قديمة إذا تعذرت قراءة مجلدات أو لم يكتمل المسح.
- [ ] حفظ المحادثات وإعادة فتح التطبيق.

## النماذج

- [ ] استيراد GGUF مباشر من Downloads عبر SAF.
- [ ] استيراد ZIP يضم `manifest.json` ثم GGUF مع تحقق SHA-256.
- [ ] استيراد مجلد GGUF بعمق 1–2، والتحقق من رفض ZIP بلا نموذج.
- [ ] تنزيل رسمي عبر Wi-Fi وبيانات الهاتف بعد موافقة المستخدم.
- [ ] فشل SHA-256 أو GGUF غير صالح: رسالة خطأ دون قبول النموذج.
- [ ] نجاح إجابة عربية من النموذج عن فقرة موجودة ومقتطف يحمل رقم مصدر.

- [ ] فهرسة 10,000 اسم ملف و1000 مستند مع مساحة تخزين ومراقبة الحرارة.
